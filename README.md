# AutoPing (PingCtl)

Массовый пинг хостов в одном терминале с интерфейсом в стиле `systemctl status`.

Вместо десятков окон `ping 1.1.1.1 -t` — один экран: точка статуса
(`●` активен / `○` деградировано / `✗` не отвечает), статистика пакетов,
среднее время ответа, история проверок и пояснение ошибки.

## Структура проекта

```
AutoPing/
├── autoping.py   # точка входа, аргументы, watch-режим
├── const.py      # константы, статусы, цвета, тайлы, шпора
├── ping_core.py  # логика пинга, парсинг вывода, чтение файла хостов
├── display.py    # вывод: таблица, прогресс-тайлы, экспорт JSON/CSV
├── .gitignore
├── README.md
└── dist/PingCtl.exe   # собранный портативный файл (не в репозиторий)
```

## Вид вывода

```
AutoPing — результаты проверки

┌ СТАТУС  ХОСТ             ИСТОРИЯ                    СТАТУС            ПАКЕТЫ   ПОТЕРЯ   СРЕДНЕ мс  ОШИБКА
└──────────────────────────────────────────────────────────────────────────────────────────────────────
●  1.1.1.1          ████▓▓░░░░░░░░░░░░░░░░░░░░░   активен          2/2     0.0%     12.0
○  8.8.8.8          ████████▓░░░░░░░░░░░░░░░░░░   деградировано    1/2    50.0%     52.0   Потеря пакетов 50.0%
✗  bad.host         ░░░░░░░░░░░░░░░░░░░░░░░░░░   не отвечает      —/—     — %       —       Узел не найден

Итого: 3 хостов, 1 активен, 1 деградировано, 1 не отвечает
```

- **ИСТОРИЯ** — вертикальные тайлы, по одному на такт пинга:
  - `█` зелёный — отвечает
  - `█` красный — не отвечает
  - `▓` жёлтый — деградировано (частичная потеря)
  - `░` серый — нет данных / пусто

## Установка

### Из исходников (требуется Python 3)

```bash
python autoping.py 1.1.1.1 8.8.8.8 ya.ru
```

### Как портативный `.exe` (без Python)

```bash
pip install pyinstaller
pyinstaller --onefile --name PingCtl autoping.py
```

Готовый файл: `dist/PingCtl.exe`. Переносите на любой компьютер с Windows и запускайте без установки Python. При повторной сборке с тем же именем файл перезаписывается.

## Использование

```bash
python autoping.py [опции] ХОСТ [ХОСТ ...]
```

### Очеловеченный ввод

Хосты можно передавать одной строкой через `;`, `,` или пробел (обязательно в кавычках в PowerShell/CMD):

```bash
python autoping.py "10.15.20.205;10.15.22.205;ya.ru"
python autoping.py 1.1.1.1 8.8.8.8 google.com
python autoping.py --file hosts.txt
```

Также поддерживается синтаксис `host:port` — порт извлекается для справки (ping/ICMP не работает с портами, это только отметка):

```bash
python autoping.py --port 1501 "10.15.20.205;ya.ru"
```

Все переданные хосты добавляются в общую таблицу.

### Примеры

| Команда | Что делает |
|---------|------------|
| `python autoping.py "1.1.1.1;8.8.8.8;ya.ru"` | Пингует 3 хоста одной строкой |
| `python autoping.py --watch 3 -c 2 -t 500 1.1.1.1 8.8.8.8` | Режим наблюдения, обновление каждые 3 сек |
| `python autoping.py --file hosts.txt --count 10 --size 64` | Хосты из файла, 10 пакетов по 64 байта |
| `python autoping.py --output json --out results.json 1.1.1.1 ya.ru` | Экспорт результата в JSON/CSV |

### Флаги

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `ХОСТ` | — | IP-адрес или домен (можно несколько, через `;` `,` пробел) |
| `-f, --file` | — | Файл со списком хостов |
| `-c, --count` | `4` | Число эхо-запросов на хост |
| `-t, --timeout` | `1000` | Таймаут ответа на пакет, мс |
| `-i, --interval` | — | Интервал между пакетами, сек (Linux/macOS) |
| `-s, --size` | — | Размер пакета, байт |
| `-w, --deadline` | — | Общее время ожидания, сек (Linux) |
| `--port N` | — | Порт для справки (ICMP не использует порты) |
| `--watch N` | — | Перерисовывать экран каждые N сек |
| `--output json\|csv` | — | Формат экспорта результатов |
| `--out ПУТЬ` | — | Куда сохранить экспорт (по умолчанию stdout) |
| `--no-color` | — | Отключить цвета |
| `-V, --version` | — | Версия программы |

## Шпора (краткая справка)

Запустите без аргументов или с `-h` — отобразится экран со всеми флагами, ejemplo вывода и кодами выхода.

## Коды выхода

| Код | Значение |
|-----|----------|
| `0` | Все хосты отвечают |
| `1` | Есть деградированные или не отвечающие хосты |
| `2` | Ошибка аргументов или чтения файла |
| `130` | Прервано пользователем (Ctrl+C) |

## Формат файла хостов (`--file`)

```
# комментарий
1.1.1.1
8.8.8.8 google.com
ya.ru, router.local
```

Пустые строки и строки, начинающиеся с `#`, игнорируются. Разделители — пробел, запятая или точка с запятой.

## Поведение при Ctrl+C

При нажатии `Ctrl+C` таблица очищается, выводится краткая итоговая сводка по всем проверенным хостам, а затем снова отображается гостевой экран со шпорой и флагами. Программа ждёт нажатия Enter перед закрытием окна.
