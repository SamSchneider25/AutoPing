# AutoPing (PingCtl)

Массовый пинг хостов и проверка TCP-портов в одном терминале с интерфейсом в стиле `systemctl status`.

Вместо десятков окон `ping 1.1.1.1 -t` — один экран: точка статуса
(`●` активен / `○` деградировано / `✗` не отвечает), статистика пакетов,
среднее время ответа, история проверок и пояснение ошибки.

## Структура проекта

```
AutoPing/
├── autoping.py   # точка входа, команды, аргументы, watch/continuous, REPL
├── const.py      # константы, статусы, цвета, тайлы, шпора
├── ping_core.py  # ICMP-пинг: парсинг вывода, валидация хостов, чтение файла
├── port_core.py  # TCP-проверка портов (host:port)
├── display.py    # вывод: таблицы ping/port, тайлы, экспорт JSON/CSV
├── .gitignore
├── README.md
└── dist/PingCtl.exe   # собранный портативный файл (не в репозиторий)
```

## Синтаксис

```
[команда] [хосты через ; , пробел] [флаги]
```

| Команда | Что делает |
|---------|------------|
| `ping ХОСТЫ [флаги]` | ICMP-пинг. Слово `ping` можно опустить, если первое слово — валидный хост |
| `port host:port ...` | Проверка TCP-порта. Своя таблица, не мешается с ping |
| `help` | Шпора со всеми флагами и примером |
| `clear` | Очистить экран (интерактив) |
| `exit` / `quit` | Выйти (синонимы) |

### Валидация

- **ping:** принимается IP (v4/v6), DNS-имя с точкой (`ya.ru`), `localhost`.
  Всё остальное (`clear`, `explain`, `bad..host`) — ошибка, не пингуется.
- **port:** принимается `host:port` с портом 1–65535. Иначе — ошибка.

## Вид вывода

### ping

```
┌ СТАТУС  ХОСТ                            ИСТОРИЯ                    СТАТУС            ПАКЕТЫ   ПОТЕРЯ   СРЕДНЕ мс  ОШИБКА
●  1.1.1.1          ████▓▓░░░░░░░░░░░░░░░░░░░░░   активен          2/2     0.0%     12.0
○  8.8.8.8          ████████▓░░░░░░░░░░░░░░░░░░   деградировано    1/2    50.0%     52.0   Потеря пакетов 50.0%
✗  bad.host         ░░░░░░░░░░░░░░░░░░░░░░░░░░   не отвечает      —/—     — %       —       Узел не найден
```

- **ИСТОРИЯ** — тайлы по тактам: `█` зелёный (отвечает), `█` красный (не отвечает),
  `▓` жёлтый (деградировано), `░` серый (нет данных).

### port

```
┌ СТАТУС  ХОСТ:ПОРТ                 СТАТУС          ВРЕМЯ мс   ОШИБКА
●  1.1.1.1:443               открыт          13.7
✗  1.1.1.1:9999              не доступен     —          Таймаут соединения
```

## Установка

### Из исходников (Python 3)

```bash
python autoping.py ping 1.1.1.1 8.8.8.8 ya.ru
```

### Портативный `.exe` (без Python)

```bash
pip install pyinstaller
pyinstaller --onefile --name PingCtl autoping.py
```

Готовый файл `dist/PingCtl.exe` переносится на любой Windows-ПК. Повторная сборка с тем же именем перезаписывает файл.

## Использование

### Интерактивный режим (без аргументов)

```bash
python autoping.py
```

```
autoping> ping 1.1.1.1;8.8.8.8;ya.ru -c 2 -t 1000
...таблица...
autoping> port 10.15.20.205:1501 --timeout 500
...таблица портов...
autoping> exit
```

После каждого прогона снова `autoping>` — программа не выходит.

### Обычный режим (с аргументами)

```bash
python autoping.py ping 1.1.1.1;8.8.8.8 -c 2 -t 1000
python autoping.py port 10.15.20.205:1501 --timeout 500
python autoping.py -t 1.1.1.1            # continuous, без остановки
```

### Флаги ping

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `-f, --file` | — | Файл со списком хостов |
| `-c, --count` | `4` | Число эхо-запросов на хост |
| `-t` | — | Пинговать без остановки (continuous) |
| `-t N` / `--timeout` | `1000` | Таймаут ответа на пакет, мс |
| `-i, --interval` | — | Интервал между пакетами, сек (Linux/macOS) |
| `-s, --size` | — | Размер пакета, байт |
| `-w, --deadline` | — | Общее время ожидания, сек (Linux) |
| `--watch N` | — | Перерисовывать экран каждые N сек |
| `--output json\|csv` | — | Экспорт результатов |
| `--out ПУТЬ` | — | Куда сохранить экспорт |
| `--no-color` | — | Отключить цвета |
| `-V, --version` | — | Версия |

### Флаги port

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `--timeout N` / `-t N` | `1000` | Таймаут TCP-соединения, мс |

## Коды выхода

| Код | Значение |
|-----|----------|
| `0` | Все хосты/порты отвечают |
| `1` | Есть деградированные / не отвечающие |
| `2` | Ошибка аргументов, валидации или чтения файла |
| `130` | Прервано пользователем (Ctrl+C) |

## Формат файла хостов (`--file`)

```
# комментарий
1.1.1.1
8.8.8.8 google.com
ya.ru, router.local
```

Пустые строки и `#` игнорируются. Разделители — пробел, запятая, точка с запятой.

## Поведение при Ctrl+C

В watch/continuous: таблица очищается, выводится краткая сводка, затем (в интерактиве)
возврат к `autoping>`. В обычном режиме — сводка и шпора, окно ждёт Enter.
